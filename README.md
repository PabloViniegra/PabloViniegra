## Los agentes también necesitan leer el README

Uso **Claude Code**, MCPs y Agent Skills para escribir código, revisar cambios y operar sobre repositorios. También trabajo con OpenCode y GitHub Copilot CLI para tareas puntuales.

En BBVA he implantado un flujo agéntico compartido por el equipo, aplicado a migraciones y testing de código heredado. Las instrucciones, skills, hooks y servidores MCP forman parte del flujo del repositorio.

> El agente propone. Los tests y la revisión tienen algo que decir.

Algunas Agent Skills que he publicado:

| Skill | Para qué |
| --- | --- |
| [`better-init`](https://github.com/PabloViniegra/better-init) | Un `/init` más preciso: genera un `CLAUDE.md` o `AGENTS.md` breve y con señal. |
| [`tell-me-the-domain`](https://github.com/PabloViniegra/tell-me-the-domain) | Reconstruye el dominio de negocio de un código desconocido a partir del repositorio. |
| [`architecture-advisor`](https://github.com/PabloViniegra/architecture-advisor) | Recomienda una arquitectura según stack y dominio, o audita la existente y propone migrarla por pasos. |
| [`clean-my-code`](https://github.com/PabloViniegra/clean-my-code) | Audita calidad y mantenibilidad con evidencia, y no toca nada sin tu aprobación. |
| [`eu-legal-compliance-audit`](https://github.com/PabloViniegra/eu-legal-compliance-audit) | Preauditoría técnica de RGPD, cookies, EAA, AI Act y DSA. No es asesoramiento legal. |
| [`improve-prompt`](https://github.com/PabloViniegra/improve-prompt) | Convierte peticiones vagas en prompts listos para un agente, con criterios de aceptación. |
